# Materialise a delayed matrix as a base matrix

Materialise a delayed matrix as a base matrix

## Usage

``` r
# S3 method for class 'delarr'
as.matrix(x, ...)
```

## Arguments

- x:

  A `delarr`.

- ...:

  Passed to
  [`collect()`](https://bbuchsbaum.github.io/delarr/reference/collect.md).

## Value

A base matrix containing the realised data.
