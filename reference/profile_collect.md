# Profile `collect()` runtime

Profile
[`collect()`](https://bbuchsbaum.github.io/delarr/reference/collect.md)
runtime

## Usage

``` r
profile_collect(x, reps = 3L, ...)
```

## Arguments

- x:

  A `delarr`.

- reps:

  Number of repetitions.

- ...:

  Additional arguments forwarded to
  [`collect()`](https://bbuchsbaum.github.io/delarr/reference/collect.md).

## Value

An object of class `delarr_profile`.
