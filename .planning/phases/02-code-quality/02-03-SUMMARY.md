## Decisions Made

**1. Implemented mmap backend instead of removing stub**
- Plan timebox was 30 minutes; implementation completed cleanly in ~4 minutes
- mmap package available and works correctly on this platform
- Implementation follows existing backend patterns (delarr_hdf5)

**2. Default to double precision (real64) for binary files**
- Most common use case for R matrix storage
- Matches writeBin(as.double()) default behavior
- Users can override with mode parameter if needed

**3. Support both persistent and one-off read modes**
- If begin() called: persistent mapping via state$m
- If not: one-off mmap/munmap in pull function
- Provides flexibility for different usage patterns

**4. File size validation before mapping**
- Calculate expected_bytes = nrow * ncol * elem_size
- Fail fast with clear error if file too small
- Prevents cryptic mmap errors from reading past file end

**5. Fixed S3 method exports as blocking issue**
- R CMD check failing: "no applicable method for 'colMeans2'"
- Added @export tags to rowMeans2.delarr and colMeans2.delarr
