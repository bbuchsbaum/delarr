  <action>
Make the compression parameter functional using hdf5r's gzip_level:

1. **Update function signature documentation:**
   Change the @param compression description from "currently unused" to document actual behavior:
   ```r
   #' @param compression Gzip compression level (0-9). Use 0 for no compression,
   #'   higher values for better compression at cost of speed. Default is 4.
   #'   Use NULL to disable compression entirely.
   ```

2. **Change default value:**
   Change `compression = NULL` to `compression = 4L` (sensible default, moderate compression)

3. **Add compression validation after other validations:**
   ```r
   gzip_level <- NULL
   if (!is.null(compression)) {
     if (!is.numeric(compression) || length(compression) != 1L ||
         compression < 0 || compression > 9) {
       stop("compression must be NULL or an integer between 0 and 9", call. = FALSE)
     }
     gzip_level <- as.integer(compression)
   }
   ```

4. **Store in environment:**
   After `env$ncol <- as.integer(ncol)`, add:
   ```r
   env$gzip_level <- gzip_level
   ```

5. **Update ensure_dataset() to use compression:**
   Change the create_dataset call (around line 81-85) from:
   ```r
   env$dset <- env$file$create_dataset(
     name = dataset,
     robj = empty,
     chunk = as.integer(chunk)
   )
   ```
   To:
   ```r
   env$dset <- env$file$create_dataset(
     name = dataset,
     robj = empty,
     chunk_dims = as.integer(chunk),
     gzip_level = env$gzip_level
   )
   ```

Note: hdf5r uses `chunk_dims` not `chunk` for the parameter name (check existing code - it may already be `chunk` which works but `chunk_dims` is more explicit).
